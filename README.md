# 💰 MinhasFinancasWebApp

Aplicação web desenvolvida com o objetivo de aprendizado em tecnologias modernas de desenvolvimento.

---

## 📌 Sobre o Projeto

O **MinhasFinancasWebApp** é um projeto pessoal criado para praticar conceitos de desenvolvimento web, incluindo back-end e front-end.

A ideia principal é simular um sistema de controle financeiro, permitindo evoluir funcionalidades ao longo do tempo enquanto aprofundo conhecimentos técnicos.

---

## 🎯 Objetivo

* Praticar desenvolvimento com C# e ASP.NET
* Aprender organização de projetos web
* Trabalhar com versionamento usando Git e GitHub
* Evoluir o projeto de forma incremental

---

## 🛠️ Tecnologias Utilizadas

* C#
* ASP.NET
* HTML, CSS e JavaScript
* Git & GitHub

---

## 🚧 Status do Projeto

🚀 Em desenvolvimento (projeto voltado para aprendizado)

---

## 🌿 Estrutura de Branches

* `master` → versão principal
* `develop` → desenvolvimento
* `feature/*` → novas funcionalidades

---

## ▶️ Como Rodar o Projeto

```bash
git clone https://github.com/nevesjp/MinhasFinancasWebApp.git
cd MinhasFinancasWebApp
dotnet run
```

Depois, abra o navegador no endereço informado pelo ASP.NET.
